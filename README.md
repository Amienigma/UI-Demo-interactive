# Spec Ledger

Interactive phone comparison demo UI from Amienigma Studios.

**Live:** [ui-demo-interactive.vercel.app](https://ui-demo-interactive.vercel.app)

Four phones, sourced — overview, compare, and light-paper ledger chrome.

## Stack

React 19 · TanStack Start · Tailwind · Vite · Vercel

```bash
npm install
npm run dev
```
